GView Controls & Shortcuts
Left Drag: Orbit view
Right Drag: Pan view
Mouse Wheel: Zoom in / out
Double Click: Center orbit pivot on surface
Shift + Right Drag: Move active model
WASD: Move camera target
Q/E, R/F, T/G: Rotate model (Rotate mode)
J/L, U/O, I/K: Translate model
+ / - : Scale active model
Ctrl + Left Drag: Box select models
Delete: Remove selected models
Ctrl + A: Select all models
Escape: Clear selection / dismiss
Ctrl + Z / Y: Undo / Redo
